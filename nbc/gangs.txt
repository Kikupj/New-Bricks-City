// New Bricks City gangs (PLAN.md §6.9). Read by NBC_Gangs (zscript/nbc/gangs.zs) at every map load.
//
// gang <id> { key = value ... }
//   name / short      full and short display names
//   tier              1-3: sets the base enemy count and the leader bounty
//   color             text colour on the board and HUD (a font colour name)
//   budget            enemy count multiplier (Swarm gangs > 1)
//   health            gang members' health multiplier
//   roster1..4        enemy choice classes (actors/enemies/Espawners.txt) by tier; spawners are resolved in code.
//                     Tier 4 (elite units) turns up once the gang's at alert 2, and in the Crown
//   leader            the leader's class; leaderhealth multiplies its health; leadertitle names it
//   escorts           how many roster2 guards stand with the leader
//   damage            pairs of <damage type> <factor> taken by gang members (NBC_Light, NBC_Shell, NBC_Rifle, Fire, Melee, Blunt)
//   painchance        multiplier on gang members' pain chance (stagger resistance < 1)
//   trait             one line for the raid board dossier
//   strength          the time of day (zscript/nbc/clock.zs): how many of them are out at each hour, a multiplier
//                     on the crew for MORNING AFTERNOON DUSK NIGHT (four numbers)
//   offguard          the share of the crew off guard at each hour (asleep, high, half-watching: slow to react), in
//                     percent, MORNING AFTERNOON DUSK NIGHT
//   hours             one line for the raid board on how they keep the clock
//   mansion           the kit floors the gang holds (PLAN.md §6.7, §6.9), "<kit>:<variant>"; a raid picks one with
//                     the case RNG. Kits and their variants (nbc/zscript/nbc/kit_*.zs):
//                       tower     occupied floor, gallery floor, gang floor, burned-out floor, penthouse floor
//                       street    tower entrance, corner stores, chop lot, under the el
//                       basement  service basement, cook lab, fight pit, parking garage, smugglers' tunnel
//                       roof      tower roof, rooftop crossing, roof camp
//   crown             1: the Landlord's own (PLAN.md §6.9, the Crown). Never dealt to a district; its raid opens once
//                     three gangs are toppled, and taking it closes the case. A placeholder until M10.
//   map / turf / env  the Crown's raid map, its name on the raid board and its environment (as in districts.txt)
// The spawn director, elites and the Sweep (PLAN.md M4; zscript/nbc/director.zs, elites.zs, objective.zs, enemyfire.zs):
//   alarm             1: when the block wakes, a reinforcement wave right away (the Collectors)
//   morale            the share of everyone they put in that has to be down before the rest give up (default 0.75)
//   volatile          how common Volatile elites are, times the usual (the Rust Saints: 2)
//   marksman          1: 25% more accurate past 512 units, a second slow to react within 256 (the Wall Watch)
//   leaderelite       the leader's elite modifiers: Armored Wired Volatile ShotCaller Landlord
//   dress             what they dress the block with, and how many: barrels <n> (explosive), sandbags <n>
// A case deals four of the regular gangs (not the Crown) to its districts.
