NEW BRICKS CITY — CREDITS
=========================

Rule for this file: never delete an entry. Every asset added to nbc/ gets a line here.
Sections below the "Imported packs" line are each pack's own credits, copied unchanged.

-------------------------------------------------------------------------------
Original work for New Bricks City
-------------------------------------------------------------------------------
Design, code and maps: the New Bricks City project.
Debris sprites (bricks, half-bricks, concrete chunk, rubble piles, tumble frames, shards; nbc/sprites/debris/):
  drawn for this project with the pxl pixel-art tool (source art/debris/debris.px.js).
  The brick-in-hand frames (BRKHA0/BRKHB0) are the FragGrenade pack's hand frame (see its credits below)
  with the grenade recoloured into a brick.

== Tactical AI ==
- zscript/nbc/tactical.zs and the nbc_ tactical CVars and menu: Tactical Duck & Dodge AI, the project owner's mod for New
  Bricks City (reference/TacticalDuckDodge/), adapted for the gang and the squad.
- It ports mechanics from the Koala AI Library (KAI) by inkoalawetrust (GPLv3; trail code by Boondorl, helpers by
  Lewisk3, Custodian, Kizoky, with RaveYard) and Smart Marines by inkoalawetrust (LGPL 2.1): 3D projectile-path
  dodging (KAI_Math.distance3dline / SM_ShouldDodgeProjectile), the mid-dodge snap shot, walking backwards while
  retreating, props as cover and running to nearby cover (SM_LocateNearbyCover). Both are kept in reference/.
